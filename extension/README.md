# MT5 SMC Advisor — розширення-радник для веб-термінала MetaTrader 5

Браузерне розширення (Chrome / Edge), яке малює **панель поверх `web.metatrader.app`** і робить **аналіз ринку за Smart Money Concepts** на кількох таймфреймах одночасно: ухил **LONG чи SHORT**, структуру, ліквідність, та запропоновані **Stop-Loss / Take-Profit** від рівнів.

> 💡 Це **помічник для аналізу, а не стратегія заробітку й не фінансова порада.**
> 🖐 Розширення **радить, а не торгує** — угоди ти відкриваєш руками у терміналі.

## Що воно робить

### 📊 Мульти-таймфрейм (одразу)
Тягне **M15 / H1 / H4 / D1 / W1** і показує ухил на кожному кольоровою смугою + зведений **HTF-ухил** (вищі таймфрейми важать більше).

### 🧠 Smart Money Concepts
Детермінований аналіз по свічках:
- **Структура ринку** — HH/HL vs LH/LL, події **BOS** (пробій структури) і **CHoCH** (зміна характеру).
- **Liquidity sweep** — стоп-хант: коли ціна знімає ліквідність за свінгом і вертається (сильний сигнал розвороту).
- **Fair Value Gap** — 3-свічковий імбаланс (зона попиту/пропозиції) як орієнтир входу.
- **Рівні ліквідності** — свінг-хай/лоу як цілі для тейків.

### 💼 Читання рахунку з вкладки (best-effort)
Розширення намагається **зчитати з відкритої вкладки MT5** твій **баланс, еквіті, вільну маржу, рівень маржі та відкриті позиції** (з нижньої панелі й таблиці угод) і показати їх у панелі. Знайдений баланс автоматично використовується для розрахунку розміру позиції. Для кожної позиції дає підказку **тримати / обережно** відносно HTF-ухилу (якщо це активний символ).

- ⚠️ Це **зчитування тексту сторінки** — працює, лише поки термінал показує ці дані як текст (перевірено на англомовній розкладці). Якщо не зчитує — напиши, надішли, як виглядає нижня панель/таблиця, і я підлаштую.
- 🚫 Розширення **не може закривати позиції** — тільки читає й радить. Клікати ордери в MT5 замість тебе воно не буде (це небезпечно й ненадійно).

### 🎯 SL/TP від структури (RR плаваючий, не 1:4)
- **Stop-Loss** — за зметеною ліквідністю / свінгом (+ буфер ATR).
- **TP1 / TP2** — до найближчих рівнів ліквідності (свінг-екстремуми); якщо структури немає — запас від ризику.
- **RR** виходить із самого ринку (напр. 1:1.6, 1:2.4, 1:3.1…), а не фіксовані −1% / +4%.

Під кожною ідеєю є блок **«Чому»** з причинами (структура, sweep, HTF-ухил, FVG, RSI-попередження).

## ⚠️ Чесно про обмеження

- Веб-термінал MT5 малюється на `<canvas>`, тому розширення **не читає ціни з самого MT5**, а бере котирування з **Binance** (крипта), **Yahoo Finance** (форекс/акції/метали) і **Stooq** (резерв). Ціна може **трохи відрізнятися** від брокера — звіряй точний вхід із терміналом.
- Для форексу немає справжнього обсягу/ордерфлоу, тому SMC рахується **по свічках** — це апроксимація популярної методології, **а не інсайд і не гарантія прибутку**.
- H4/W1 для форексу будуються агрегацією з H1/D1 (наближено); для крипти H4 — нативний.

**Символ:** кнопка 🎯 (авто) намагається зчитати символ із заголовка вкладки MT5. Якщо термінал не виводить символ у заголовок — просто **впиши вручну** (напр. `AUDCAD`). Якщо в панелі стоїть `EURUSD`, а графік інший — панель показує **не той інструмент**; вибери правильний символ.

## Встановлення (3 кроки)

1. Завантаж папку `extension/` на свій компʼютер (або весь репозиторій).
2. Відкрий у браузері `chrome://extensions` (в Edge — `edge://extensions`).
3. Увімкни **Developer mode** → **Load unpacked** → вибери папку `extension/`.

Готово. Відкрий **[web.metatrader.app/terminal](https://web.metatrader.app/terminal)** — праворуч зʼявиться панель **🧠 MT5 SMC Advisor**.

## Як користуватися

1. **Символ.** 🎯 (зелена = авто) підхоплює символ графіка; або впиши вручну / тисни швидку кнопку.
2. **Сетап на:** обери таймфрейм для деталізованої ідеї (**M1 / M5 / M15 / M30 / H1 / H4 / D1 / W1**). Смуга вище показує ухил на стандартних ТФ. *(Нижче 15хв дані з безкоштовних джерел обмеженіші й шумніші.)*
3. У **⚙️ Налаштування** задай баланс, плече, ризик % (розмір позиції), а також **ATR період** і **Свінги (сила)** пивотів.
4. Дивись картку:
   - Кольорова **MTF-смуга** + зведений **HTF-ухил**
   - **Структура** (напр. `висхідна · BOS↑`), RSI, ATR, **Liquidity sweep**
   - 📈/📉 **Ідея: LONG/SHORT**, 🎯 вхід, 🛑 SL, ✅ **TP1/TP2**, ⚖️ **RR** (плаваючий)
   - Блок **«Чому»** з причинами
   - Розмір позиції, маржа, ризик $, потенціал $
   - ⏳ **ЧЕКАЙ** — коли таймфрейми не узгоджені (немає чіткого сетапу)
5. Панель **перетягується** за заголовок, згортається (—), закривається (✕), а **↺** скидає позицію вікна (якщо воно кудись «поїхало»). Вікно не буває вищим за екран — зайве прокручується всередині.
