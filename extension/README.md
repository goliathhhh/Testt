# MT5 Web Advisor — розширення-радник для веб-термінала MetaTrader 5

Браузерне розширення (Chrome / Edge), яке малює **панель поверх `web.metatrader.app`** і дає **підказки з аналізу ринку**:
ухил **LONG чи SHORT**, орієнтир входу, запропоновані **Stop-Loss / Take-Profit**, RR та розмір позиції.

> 💡 Це **помічник для аналізу, а не стратегія заробітку й не фінансова порада.**
> 🖐 Розширення **радить, а не торгує** — угоди ти відкриваєш руками у терміналі.
> 🔎 Ухил визначається трендом по **EMA(9)** з фільтром **RSI(7)**.

## Динамічні SL/TP (не фіксовані)

Розширення **саме пропонує рівні за поточним ринком**, а не сталі −1% / +4%:

- **Stop-Loss** — за найближчим свінг-рівнем (мін/макс за останні N барів) з буфером, обмежений волатильністю **ATR**.
- **Take-Profit** — кратне до **ATR** (за замовч. 3× ATR), тож ціль масштабується під поточну волатильність.
- **RR** виходить **плаваючим** і залежить від ринку (типово ≈ 1.5–3).

Тому на спокійному ринку рівні вузькі, на волатильному — ширші. Усі множники можна змінити в **⚙️ Налаштування**.

## ⚠️ Важливо розуміти

Веб-термінал MT5 малюється на `<canvas>`, тому розширення **не читає ціни з самого MT5**. Воно бере котирування з незалежних джерел і рахує сигнал:

- **Binance** — для крипти (BTCUSD, ETHUSD…)
- **Yahoo Finance** — форекс/акції/метали
- **Stooq** — резервне джерело (денні дані)

Через це ціна в панелі може **трохи відрізнятися** від ціни твого брокера. Використовуй панель як **пораду щодо напрямку та рівнів**, а точний вхід — за ціною терміналу.

## Встановлення (3 кроки)

1. Завантаж цю папку `extension/` на свій компʼютер (або весь репозиторій).
2. Відкрий у браузері `chrome://extensions` (в Edge — `edge://extensions`).
3. Увімкни **Developer mode** (перемикач угорі праворуч) → натисни **Load unpacked / Завантажити розпаковане** → вибери папку `extension/`.

Готово. Тепер відкрий **[web.metatrader.app/terminal](https://web.metatrader.app/terminal)** — праворуч на графіку зʼявиться панель **📊 MT5 Advisor**.

## Як користуватися

1. Введи символ (напр. `EURUSD`) або тисни швидку кнопку (EURUSD, GBPUSD, USDJPY, AUDCAD, BTCUSD, ETHUSD).
2. Обери таймфрейм (M5 / M15 / M30 / H1 / H4 / D1).
3. У блоці **⚙️ Налаштування** задай баланс, плече, ризик % (розмір позиції), а також параметри рівнів: **ATR період**, **TP = × ATR**, **Свінг, барів**.
4. Дивись картку-підказку:
   - 📈 **Ухил: LONG** / 📉 **Ухил: SHORT** — напрямок тренду
   - EMA, RSI, **ATR (волатильність)**
   - 🎯 орієнтир входу, 🛑 Stop-Loss, ✅ Take-Profit (з поточними %), ⚖️ RR (плаваючий)
   - 💼 розмір позиції, ⚙️ маржа, 🔻 ризик $, 🎯 потенціал до TP $
   - 🚫 **ЗАБЛОКОВАНО** — коли RSI перекуплений/перепроданий (краще зачекати)
5. Панель можна **перетягувати** за заголовок, згортати (—) і закривати (✕). Кнопка розширення в тулбарі показує/ховає її.

## Що в папці

| Файл | Призначення |
|---|---|
| `manifest.json` | Опис розширення (Manifest V3) |
| `background.js` | Завантаження котирувань (Yahoo / Binance / Stooq) |
| `indicators.js` | Розрахунок RSI / EMA / ATR і динамічних рівнів |
| `content.js` | Панель поверх веб-термінала |
| `panel.css` | Стилі панелі |
| `popup.html` / `popup.js` | Вікно кнопки в тулбарі |

## ⚠️ Застереження

Це навчальний інструмент-помічник. Сигнали не є фінансовою порадою й не гарантують прибутку.
Спершу перевіряй усе на **демо-рахунку**. Торгівля повʼязана з ризиком втрати капіталу.
