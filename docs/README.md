# RSI Expert Advisor для MetaTrader 5

Торговий робот (Expert Advisor) на MQL5, що торгує за індикатором **RSI** з повноцінним керуванням ризиком.

## Логіка стратегії

- **BUY** — коли RSI виходить угору із зони перепроданості (перетинає рівень `Oversold`, напр. 30 знизу вгору).
- **SELL** — коли RSI виходить донизу із зони перекупленості (перетинає рівень `Overbought`, напр. 70 згори вниз).
- Сигнали розраховуються **по закритому бару** (щоб уникнути перемальовування та зайвих входів усередині бару).
- Опційний **фільтр тренду по MA**: купувати лише вище середньої, продавати лише нижче.

## Що вміє робот

| Функція | Опис |
|---|---|
| **Stop Loss / Take Profit** | У пунктах, задаються в налаштуваннях. `0` = вимкнено. |
| **Trailing Stop** | Підтягує стоп за ціною після досягнення заданого прибутку. |
| **Break-even** | Переносить стоп у беззбиток (+фіксований прибуток) після досягнення тригера. |
| **Авторозрахунок лота** | Розмір позиції за % ризику від балансу (або фіксований лот). |
| **Фільтр тренду (MA)** | Торгівля лише за напрямком середньої. |
| **Фільтр спреду** | Не входить, якщо спред більший за дозволений. |
| **Фільтр годин** | Торгує лише у вказаному часовому вікні (за часом сервера). |
| **Magic number** | Робот керує лише своїми угодами, не чіпає ручні/інші EA. |
| **Ліміт позицій** | Максимальна к-сть одночасних угод. |

## Встановлення

1. Відкрий MetaTrader 5 → меню **File → Open Data Folder**.
2. Скопіюй файл `Experts/RSI_Expert_Advisor.mq5` у папку `MQL5/Experts/`.
3. У **MetaEditor** (F4) відкрий файл і натисни **Compile** (F7). Має зʼявитися `RSI_Expert_Advisor.ex5` без помилок.
4. У терміналі онови список у вікні **Navigator** (правий клік → Refresh).
5. Перетягни радника на графік потрібного символу/таймфрейму.
6. Увімкни **Algo Trading** (кнопка на панелі) та постав галочку **Allow Algo Trading** у діалозі радника.

## Рекомендації перед реальною торгівлею

1. **Спочатку бектест.** Відкрий **Strategy Tester** (Ctrl+R), обери радника, символ, період і прожени історію.
2. **Оптимізуй** ключові параметри: `InpRSIPeriod`, рівні `Overbought/Oversold`, `InpStopLoss`, `InpTakeProfit`.
3. **Тестуй на демо-рахунку** щонайменше кілька тижнів.
4. Починай з **малого ризику** (`InpRiskPercent` = 0.5–1.0%).

## Основні параметри

| Параметр | За замовч. | Опис |
|---|---|---|
| `InpRSIPeriod` | 14 | Період RSI |
| `InpRSIOverbought` | 70 | Рівень перекупленості |
| `InpRSIOversold` | 30 | Рівень перепроданості |
| `InpUseTrendFilter` | true | Увімкнути фільтр тренду по MA |
| `InpMAPeriod` | 200 | Період MA для фільтра |
| `InpLotMode` | LOT_RISK | Режим лота: ризик % або фіксований |
| `InpRiskPercent` | 1.0 | Ризик на угоду, % від балансу |
| `InpFixedLot` | 0.10 | Фіксований лот (якщо LOT_FIXED) |
| `InpStopLoss` | 300 | Stop Loss, пункти |
| `InpTakeProfit` | 600 | Take Profit, пункти |
| `InpUseTrailing` | true | Трейлінг-стоп |
| `InpTrailingStart` | 200 | Прибуток для старту трейлінгу, пункти |
| `InpTrailingStop` | 150 | Дистанція трейлінгу, пункти |
| `InpUseBreakEven` | true | Перенос у беззбиток |
| `InpMaxPositions` | 1 | Макс. одночасних позицій |
| `InpMaxSpread` | 30 | Макс. дозволений спред, пункти |

## ⚠️ Застереження

Це навчальний/стартовий шаблон. Торгівля на фінансових ринках повʼязана з ризиком втрати капіталу.
Жодна стратегія не гарантує прибутку. Використовуй на власний ризик і **обовʼязково тестуй на демо** перед реальними коштами.
