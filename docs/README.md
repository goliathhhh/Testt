# RSI Expert Advisor для MetaTrader 5 — авто-трейдинг EURUSD

Торговий робот (Expert Advisor) на MQL5, що **сам відкриває й закриває угоди** в MetaTrader 5 за індикаторами **RSI + EMA** з повноцінним керуванням ризиком і опційними **сповіщеннями в Telegram**.

> ⚠️ **Спочатку — тільки на ДЕМО-рахунку.** Торгівля повʼязана з ризиком втрати капіталу. Жодна стратегія не гарантує прибутку.

## Швидкий старт (EURUSD, демо)

1. Відкрий/створи **демо-рахунок** у MetaTrader 5 (File → Open an Account → обери Demo).
2. MT5 → **File → Open Data Folder** → скопіюй `Experts/RSI_Expert_Advisor.mq5` у папку `MQL5/Experts/`.
3. У **MetaEditor** (F4) відкрий файл → **Compile (F7)**. Має зʼявитися `RSI_Expert_Advisor.ex5` без помилок.
4. У терміналі: **Navigator → Expert Advisors → Refresh** (правий клік).
5. Відкрий графік **EURUSD** (напр. таймфрейм **M15**).
6. Перетягни радника на графік EURUSD.
7. У діалозі постав галочку **Allow Algo Trading** → OK.
8. Увімкни кнопку **Algo Trading** на верхній панелі (має світитися зеленим).

Готово — на кожному новому барі бот перевіряє сигнал і сам відкриває угоди на демо. У куті графіка має бути 🙂 (радник активний).

## Логіка стратегії

Два режими сигналу (`InpSignalMode`):

- **RSI_CROSS** (за замовч.) — BUY, коли RSI виходить угору із зони перепроданості; SELL, коли RSI виходить донизу із зони перекупленості. Опційний фільтр тренду по EMA (купувати вище EMA, продавати нижче).
- **TREND_RSI** — напрямок за EMA (ціна вище EMA → LONG, нижче → SHORT), а RSI слугує фільтром перекупленості/перепроданості. Це та сама логіка, що в Telegram-боті *Phantom Trader*.

Сигнали рахуються **по закритому бару** (без перемальовування).

## Що вміє робот

| Функція | Опис |
|---|---|
| **Авто-трейдинг** | Сам відкриває й закриває позиції — без ручного втручання. |
| **Stop Loss / Take Profit** | У **пунктах** або у **відсотках** від ціни (RR 1:4 «з коробки»). |
| **Trailing Stop** | Підтягує стоп за ціною після заданого прибутку. |
| **Break-even** | Переносить стоп у беззбиток. |
| **Авторозрахунок лота** | Розмір позиції за % ризику від балансу. |
| **Фільтр тренду (EMA)** | Торгівля лише за напрямком середньої. |
| **Фільтр спреду / годин** | Не входить при завеликому спреді або поза заданим вікном. |
| **Telegram-сповіщення** | Повідомлення про кожне відкриття/закриття угоди. |
| **Magic number** | Керує лише своїми угодами. |

## Оптимізовані параметри (перенесені з Telegram-бота)

| Параметр | Значення | Опис |
|---|---|---|
| `InpRSIPeriod` | 7 | Період RSI |
| `InpRSIOverbought` | 70 | Рівень перекупленості |
| `InpRSIOversold` | 35 | Рівень перепроданості |
| `InpMAPeriod` | 9 | Період EMA (тренд) |
| `InpRiskPercent` | 3.0 | Ризик на угоду, % від балансу |
| `InpStopMode` | STOP_PERCENT | Режим стопів (% від ціни) |
| `InpStopLossPct` | 1.0 | Stop Loss, % |
| `InpTakeProfitPct` | 4.0 | Take Profit, % → **RR 1:4** |

## Telegram-сповіщення (опційно)

1. Створи бота через [@BotFather](https://t.me/BotFather) → отримай **токен**.
2. Дізнайся свій **chat_id**: напиши боту `/start`, відкрий
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, знайди `"id"` у розділі `"chat"`.
3. У MT5: **Tools → Options → Expert Advisors** → постав галочку
   **Allow WebRequest for listed URL** і додай:
   ```
   https://api.telegram.org
   ```
4. У параметрах радника:
   - `InpUseTelegram = true`
   - `InpTelegramToken = <твій токен>`
   - `InpTelegramChat = <твій chat_id>`

> 🔒 Токен вводиться **в параметрах радника у терміналі**, а не в коді — тому він не потрапляє в git.

## Перед реальними коштами

1. **Бектест.** Strategy Tester (Ctrl+R) → обери радника, `EURUSD`, період → прожени історію.
2. **Оптимізуй** ключові параметри (RSI, рівні, SL/TP).
3. **Тестуй на демо** щонайменше кілька тижнів.
4. Починай з **малого ризику** і лише потім розглядай реальний рахунок.
