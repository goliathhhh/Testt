# MultiSymbol ScannerBot — сканер усіх символів для MT5

EA, який з **одного графіка** сканує **багато символів** (Market Watch або твій список), оцінює кожен за силою тренду і відкриває угоди лише на **найкращих** сетапах. Тримає позицію, поки живе тренд — тому угоди тривають **від годин до 3 діб**.

> ⚠️ Жоден бот не гарантує прибутку. Скоринг лише обирає найсильніші тренди з доступних. Спершу — демо.

## Логіка

1. Кожні 20 сек сканує символи: напрямок за **EMA 12/48 (H1)**, сила за **ADX**, підтвердження на **H4**.
2. **Score = ADX + (відрив EMA / ATR)×10 + бонус за збіг H4.** Входить тільки якщо score ≥ `InpMinScore` і ADX ≥ `InpAdxMin`.
3. Відкриває до `InpMaxPositions` (3) позицій на **різних символах** — обирає топ за балом.
4. Виходи: **розворот тренду** / **ATR-трейлінг** / **беззбиток** / жорсткий ліміт **72 год** / п'ятниця ввечері — все закрити.
5. **Денний ліміт збитку 3%** — після нього нові угоди не відкриваються до завтра.
6. Лот — від ризику 1% з ATR-стопом, з підгонкою під вільну маржу (`OrderCalcMargin`) — **плече знати не треба**.

## Встановлення (VPS)

```bash
EXPDIR=$(find ~/.wine -ipath '*Terminal*/MQL5/Experts' -type d | head -1)
wget -O "$EXPDIR/MultiSymbol_ScannerBot.mq5" \
  https://raw.githubusercontent.com/goliathhhh/Testt/claude/metatrader5-script-bot-35b2r1/Experts/MultiSymbol_ScannerBot.mq5
```

1. MetaEditor (F4) → відкрити файл → **Compile (F7)** → `0 errors`.
2. **Зніми FlipBot із графіка** (правий клік → Expert List → Remove), щоб два боти не торгували паралельно.
3. Перетягни `MultiSymbol_ScannerBot` на **будь-який один графік** (наприклад EURUSD H1) → Allow Algo Trading → OK.
4. Статус видно прямо на графіку (лівий верхній кут): кандидати, бали, денний P/L.

## Ключові параметри

| Параметр | Замовч. | Опис |
|---|---|---|
| `InpSymbols` | AUTO | AUTO = усі з Market Watch (до 20), або список: `EURUSD,GBPUSD,XAUUSD` |
| `InpMinScore` | 30 | Поріг входу (вище = рідше, але якісніше) |
| `InpAdxMin` | 22 | Мінімальна сила тренду |
| `InpMaxPositions` | 3 | Одночасних позицій (різні символи) |
| `InpRiskPercent` | 1.0 | Ризик на угоду, % балансу |
| `InpMaxDailyLoss` | 3.0 | Денний стоп-збиток, % |
| `InpMaxHoldHours` | 72 | Макс. тримання (3 доби) |
| `InpFridayFlat` | true | Закривати все в п'ятницю ввечері |

💡 Додай у Market Watch символи, які хочеш сканувати (правий клік → Symbols). Що більше якісних інструментів — то більше вибір у скоринга.

## Фільтри якості входів (v1.10)

Усі вмикаються/вимикаються в налаштуваннях — можна порівнювати «до/після» на демо:

| Фільтр | Параметри | Що робить |
|---|---|---|
| 📰 **Новини** | `InpUseNewsFilter`, 45 хв до / 30 після | Не входить біля важливих новин (вбудований календар MT5) по валютах символу. У Strategy Tester календар недоступний — фільтр просто не блокує. |
| 🎯 **Вхід на відкаті** | `InpPullbackEntry` | Входить лише коли закритий бар торкнувся EMA(12) і відновив рух — не «женеться» за ціною. Входи рідші, але якісніші. |
| ⏰ **Сесії** | `InpUseSession`, 9–22 | Нові входи тільки в ліквідні години (Лондон/НЙ, серверний час). Керування позиціями працює цілодобово. |
| 💰 **Частковий тейк** | `InpUsePartialTP`, 50% на ~1R | На прибутку ≈1R закриває половину і переносить стоп у беззбиток — багато угод гарантовано в плюсі. |
| 🔗 **Кореляція** | `InpMaxPerCurrency=1` | Не тримає кілька позицій з однією валютою (EURUSD+GBPUSD = подвійна ставка проти USD). |
| 🧯 **Пауза після збитків** | `InpMaxLossStreak=3`, 4 год | Після 3 стопів поспіль — пауза: ринок зараз не для стратегії. |
| 🌪 **Хаос-фільтр** | `InpAtrSpikeMult=2.0` | Не входить, коли ATR удвічі вище за свою норму (паніка/новини — трендові сигнали брешуть). |

> Через фільтри входи стануть **помітно рідшими** — це нормально: мета — якість, а не кількість. Хочеш більше угод — вимкни `InpPullbackEntry` або знизь `InpMinScore`.
